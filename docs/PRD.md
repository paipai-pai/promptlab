# PromptLab 产品需求文档

## 1. 文档目的

本文档定义 PromptLab MVP 的产品边界、核心业务规则、主要流程与验收基线。未在本文确认的能力不自动进入开发范围。

## 2. 产品定位

PromptLab 是面向 AI 开发者、产品经理和 AI 创作者的个人 Prompt 资产管理与实验平台。它解决 Prompt 分散、模板难以复用、修改缺少追溯、实验结果与具体版本脱节的问题。

核心价值：

- 统一管理 Prompt 资产及元数据。
- 使用 `{{variable_name}}` 变量复用单一文本模板。
- 以不可变版本保留正文演进历史。
- 将人工实验完整关联到已保存版本。
- 通过评分与备注支持持续评价和迭代。

## 3. 目标用户

- AI 开发者：沉淀开发、调试和评估中使用的 Prompt。
- 产品经理：管理产品场景 Prompt，并记录版本与实验结论。
- AI 创作者：复用内容或图像生成模板，比较人工实验效果。

MVP 是单用户私有工作区体验；不同用户之间的数据彼此隔离。

## 4. MVP 范围

### 4.1 Prompt 资产

每个 Prompt 包含名称、描述、分类和正文模板。分类固定为：编程开发、产品工作、内容创作、图像生成、学习研究、其他。

名称、描述、分类属于 Prompt 元数据。修改这些字段不创建正文版本。正文由已保存版本承载。

### 4.2 模板变量

- 正文使用单一纯文本模板。
- 变量语法固定为 `{{variable_name}}`。
- 界面从模板中识别变量，并允许填写实际输入。
- 未保存草稿可以预览和复制渲染结果。
- 未保存草稿不能创建正式实验。

### 4.3 版本历史

- 首次保存正文时创建第一个版本。
- 修改正文后，由用户明确执行“保存为新版本”。
- 每次保存生成新的不可变版本，历史版本不可修改或覆盖。
- 用户可查看旧版本及其正文，但不能就地编辑旧版本。

### 4.4 手动实验

实验只能关联一个已保存的 Prompt 版本，并保存版本引用、实际输入快照、模型名称、模型输出、评分和备注。

MVP 不调用模型 API。用户在外部完成调用后，手动填写并保存结果。

### 4.5 身份与隐私

- 用户通过 Supabase Auth 登录。
- 所有业务请求在服务端确认用户身份。
- 所有业务表启用 Supabase RLS。
- 默认只允许用户访问自己的 Prompt、版本和实验。

## 5. 明确不做

- 模型 API 调用或密钥托管
- 团队空间、共享、协作审批
- 社区、公开模板市场
- 自动 Prompt 优化或自动评分
- 富文本、多段消息模板或工作流编排
- 未确认的数据导入、导出与批量操作

## 6. 核心流程

### 6.1 创建 Prompt

1. 用户进入新建界面。
2. 填写名称、描述、固定分类和正文模板。
3. 系统校验输入和变量语法。
4. 用户保存 Prompt。
5. 系统创建 Prompt 元数据和首个不可变正文版本。

### 6.2 编辑与预览草稿

1. 用户打开 Prompt 最新版本。
2. 修改正文形成仅存在于编辑会话中的草稿。
3. 系统识别变量，用户填写实际值。
4. 用户可预览或复制渲染结果。
5. 草稿未保存前，实验入口不可用于建立正式关联。

### 6.3 保存新版本

1. 用户对正文作出修改。
2. 用户明确点击“保存为新版本”。
3. 服务端校验权限、输入与并发状态。
4. 系统追加一个新版本；旧版本保持不变。

### 6.4 记录实验

1. 用户从一个已保存版本发起实验记录。
2. 填写实际变量输入、模型名称、输出、评分和备注。
3. 服务端校验版本归属和输入。
4. 系统保存版本引用和当次输入快照。

## 7. 功能验收基线

- 登录用户只能读取、创建和修改属于自己的可变业务数据。
- 列表与详情准确展示 Prompt 名称、描述、分类和当前已保存版本。
- 分类值只能来自六个固定选项。
- 系统能从正文中识别合法的 `{{variable_name}}` 占位符。
- 修改元数据不会生成正文版本。
- 正文改变后不会自动覆盖历史；只有显式保存才会追加版本。
- 任一历史版本的正文在后续操作中保持不变。
- 未保存草稿可预览和复制，但不能关联实验。
- 实验记录保存后仍指向创建时选定的版本，并保留输入快照。
- 空态、加载态、校验错误和服务端错误均有明确反馈。
- 核心路径在明暗主题和常见桌面/移动宽度下可用。

## 8. 待确认事项

- 模型名称采用自由输入、建议列表还是固定枚举。
- 正文未变化时是否允许创建一个内容相同的新版本。
- 并发编辑发生冲突时的具体交互。

P2-02 已确认：评分为可空的 1–5 整数且可受控修改；failed 实验不允许评分并必须记录失败原因；Prompt 删除级联删除版本与实验，实验可单独删除，不实现软删除；历史版本不可直接修改或删除；数据库字段长度以 `docs/DATABASE.md` 为准。变量名规则沿用 Phase 1：英文变量名、数字和下划线，且不能以数字开头，同名变量合并展示。
